# Quick Love

Original Quick Love Regular font by Darrell Flood, supplied by the user.
The original TTF bytes are unchanged. See [the supplied license](Quick-Love-License.txt).

The test Universal UI downloads this file into its private executor cache and creates a local Roblox font-family manifest. Only text belonging to the test UI receives its FontFace. Game interfaces, PlayerGui, and installed Roblox font files are not changed. Unsupported executors retain the existing UI font.
